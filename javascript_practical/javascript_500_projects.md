# 500 JavaScript Projects — From Zero to Mastery

> Every project is tied to a **JS concept you'll learn by building it**.
> This is not just a project list — it's a complete JavaScript curriculum disguised as projects.
> Build in order. Each section builds on the last.

---

## 📖 HOW TO USE THIS LIST

Each project shows:
- 🧠 **Concept** — The JS skill this project teaches
- 🔨 **What you build** — The actual thing to make

Don't skip levels. The beginner projects teach the foundations everything else rests on.

```
Weeks 1–6:     Projects 1–60     → Variables, DOM, events, functions
Weeks 7–14:    Projects 61–140   → ES6+, async, APIs, Canvas
Weeks 15–22:   Projects 141–200  → OOP, modules, storage, state
Weeks 23–34:   Projects 201–280  → Node.js, React, TypeScript

Weeks 45–52:   Projects 351–420  → Real-time, "build your own", capstones
Year 2+:       Projects 421–500  → Engine internals, mastery specializations
```

> **The secret:** Every project on this list teaches you *why*, not just *how*.
> When you build your own React, you'll never be confused by `useEffect` again.
> When you build your own Promise, async/await becomes obvious.
> **Build to understand. Understand to master.**

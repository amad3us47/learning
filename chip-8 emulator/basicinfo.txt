$C622 inside of the original game boy ($C6) says ADD to register A, and byte ($22) is the value that would be added to register A. 

$7522 says ($75) add to register 5 with the value of ($22).


What is an emulator?
An emulator reads the original machine code instructions that were assembled for the target machine, interprets them and then make it run on the host machine.
When an emulator reads the instruction ($7522), it would emulate the behaviour of CHIP-8 by doing

              registers[5] += 0x22;

What is a register?
A register is a dedicated location on a CPU for storage.Any operations that a CPU does must be done within its registers.A CPU typically only has a few registers, so long-term data is held in memory instead.Operations often involve loading data from memory into registers, operating on those registers, and storing the result back into memory.

CHIP-8 has sixteen 8-bit registers, labeleld V0 to VF. Each register is able to hold any value from 0x00 to 0xFF(255 in decimal).

CHIP-8 has 4096 bytes from 0x000 to 0xFFF.

The address is divided in three sections:
- 0x000-0x1FF: Originally reserved for CHIP-8 interpreter
- 0x050-0x0A0: Storage space for built-in characters(0 though F), which we will need to manually put into our memory because ROMs will be looking for those characters.
- 0x200-0xFFF: Instructions from the ROM will be stored starting at 0x200, and anything left after the ROM's space is free to use.
